# Notetacker

## Features
- Create notes
- Edit notes
- Delete notes
- Search notes
- Rich text editing with Quill
- Local persistence using localStorage
- Live word count
- Active note highlighting

## Built With
- HTML5
- CSS3
- JavaScript (ES6)
- Quill.js

## What I Learned
- CRUD operations
- Application state management
- Event delegation
- localStorage
- Array methods (find, filter, forEach)
- DOM manipulation
